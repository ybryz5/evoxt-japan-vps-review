这块得说实话——**Evoxt 东京机房不是 CN2 GIA，也不是 9929/CMIN2 优化线路，走的是标准的 PCCW 国际路由**。具体数据如下（基于 159 个国内节点的实测）：

| 运营商 | 平均延迟 | 路由特点 |
| --- | --- | --- |
| 中国移动 | 179 ms | 经香港 CMI 出境，PCCW 转入东京，体验最好 |
| 中国电信 | 336 ms | 163 骨干 + 美国节点绕行 + PCCW，绕路明显 |

**回程路由**全部走 PCCW 转入：电信回程 PCCW→163、联通回程 PCCW（无联通优化）、移动回程 PCCW→CMI。

国际段延迟倒是不错：东京本地 2 ms，到香港约 50 ms，到洛杉矶约 113 ms，到法兰克福约 237 ms。

**结论很直接：** 如果你期望 Evoxt 东京机房像搬瓦工 CN2 GIA 那样给国内用户提供 50ms 以内的低延迟，那会失望。它更适合**移动用户**（179ms 还算能用），电信和联通用户拿到 300+ ms 是常态。

这也呼应了为什么 Evoxt 要把大阪做成 Premium 网络——优质路由可能改善回程，但即便如此它走的也不是 CN2 优化，只是相对更好的国际线路。
